# C/C++ Unit Test Demo with CppUTest


## Contents:

- src/ - Source code and component (with average/) for building the demo application
- tests/ - Unit tests for the component (average/ ring_buffer/ and mock_sensor/)
- Makefile - For building the application or running the unit tests
- Dockerfile - Creates a Docker image that automatically runs all unit tests with CppUTest (TDB)
- .github/workflows - GitHub Actions workflows for automatically running tests (TDB)

## prepare cpputest/
```bash
$ cd ~/github
$ git clone https://github.com/cpputest/cpputest.git
$ cd cpputest
$ sudo apt install build-essential autoconf automake libtool
$ autoreconfig -i
$ ./configure
$ make
```

## cpputest/build/MakefileWorker.mk
>----------
> Inputs - these variables describe what to build
>
>>	**INCLUDE_DIRS** - Directories used to search for include files.
>>                   This generates a **-I** for each directory.<br>
>>	**SRC_DIRS** - Directories containing source files to build into the library<br>
>>	**SRC_FILES** - Specific source files to build into library. Helpful when not all code
>>				in a directory can be built for test (hopefully a temporary situation)<br>
>>	**TEST_SRC_DIRS** - Directories containing unit test code build into the unit test runner.
>>				These do not go in a library. They are explicitly included in the test runner<br>
>>	**TEST_SRC_FILES** - Specific source files to build into the unit test runner.
>>				These do not go in a library. They are explicitly included in the test runner<br>
>>	**MOCKS_SRC_DIRS** - Directories containing mock source files to build into the test runner.
>>				These do not go in a library. They are explicitly included in the test runner<br>
>>	**MOCKS_SRC_FILES** - Specific mock source files to build into the unit test runner
>>				These do not go in a library. They are explicitly included in the test runner<br>
>----------
> You can adjust these variables to influence how to build the test target
> and where to put and name outputs
> See below to determine defaults
>>   **COMPONENT_NAME** - the name of the thing being built<br>
>>   **TEST_TARGET** - name of the test executable. By default it is
>>			$(COMPONENT_NAME)_tests.
>>		Helpful if you want 1 > make files in the same directory with different
>>		executables as output.<br>
>>   **CPPUTEST_HOME** - where CppUTest home dir found<br>
>>   TARGET_PLATFORM - Influences how the outputs are generated by modifying the
>>       CPPUTEST_OBJS_DIR and CPPUTEST_LIB_DIR to use a sub-directory under the
>>       normal objs and lib directories.  Also modifies where to search for the
>>       CPPUTEST_LIB to link against.
>>   CPPUTEST_OBJS_DIR - a directory where o and d files go<br>
>>   CPPUTEST_LIB_DIR - a directory where libs go<br>
>>   CPPUTEST_ENABLE_DEBUG - build for debug<br>
>>   CPPUTEST_USE_MEM_LEAK_DETECTION - Links with overridden new and delete<br>
>>   CPPUTEST_USE_STD_CPP_LIB - Set to N to keep the standard C++ library out
>>		of the test harness<br>
>>   CPPUTEST_USE_GCOV - Turn on coverage analysis.
>>		Clean then build with this flag set to Y, then 'make gcov'<br>
>>   CPPUTEST_USE_GCOV_NO_GCNO_FILES - Disable gcov's .gcno files from being generated<br>
>>   CPPUTEST_MAPFILE - generate a map file<br>
>>   CPPUTEST_WARNINGFLAGS - overly picky by default<br>
>>   OTHER_MAKEFILE_TO_INCLUDE - a hook to use this makefile to make
>>		other targets. Like CSlim, which is part of fitnesse<br>
>>   CPPUTEST_USE_VPATH - Use Make's VPATH functionality to support user
>>		specification of source files and directories that aren't below
>>		the user's Makefile in the directory tree, like:
>>			_SRC_DIRS += ../../lib/foo_
>>		It defaults to N, and shouldn't be necessary except in the above case.<br>
>  Other flags users can initialize to sneak in their settings
>>	CPPUTEST_CXXFLAGS - flags for the C++ compiler<br>
>>	CPPUTEST_CPPFLAGS - flags for the C++ AND C preprocessor<br>
>>	CPPUTEST_CFLAGS - flags for the C complier<br>
>>	CPPUTEST_LDFLAGS - Linker flags<br>
>>	CPPUTEST_CXX_PREFIX - prefix for the C++ compiler<br>
>>	CPPUTEST_CC_PREFIX - prefix for the C compiler<br>
